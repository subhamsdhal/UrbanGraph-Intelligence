# EG006 Synthetic Power Grid Fixture

## Overview
The `eg006` fixture models a 6-bus synthetic transmission network operating at 230 kV nominal voltage.

## Components
- **Buses**: 6 buses (Bus 1 Slack, Bus 2-3 PV Generator buses, Bus 4-6 PQ Load buses).
- **Branches**: 7 transmission lines with specified reactance ($X$), resistance ($R$), and MVA thermal ratings.
- **Generators**: 3 generation units (hydro, gas thermal, solar photovoltaic).
- **Loads**: 3 primary load centers representing commercial, residential, and industrial zones.
